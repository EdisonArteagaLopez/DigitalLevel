# Digital Level

Android bubble level app using the device's built-in accelerometer and gravity sensors.

## Features
- Real-time tilt measurement
- Visual bubble level indicator
- Angle display in degrees
- Portrait and landscape support

## Requirements
- Android Studio
- Android SDK 21+
- Device with accelerometer sensor

## Installation
```bash
git clone git@github.com:EdisonArteagaLopez/DigitalLevel.git
```
Open in Android Studio → Build → Run
